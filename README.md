# Мобильный сайт с нейросетью

## Описание
Это полноценный мобильный веб-сайт с интеграцией нейросети, разработанный с использованием современных веб-технологий и адаптированный для использования на мобильных устройствах.

## Цветовая палитра
- Белый: `#ffffff`
- Черный: `#000000`
- Светло-серый: `#e6e6e6`
- Темно-серый: `#1a1a1a`
- Средне-серый: `#cccccc`
- Серый текст: `#333333`
- Переливающийся золотой: `linear-gradient(45deg, #D4AF37, #FFD700, #F9D71C)`

## Структура проекта
```
/workspace/
├── index.html          # Главная страница с интерфейсом нейросети
├── history.html        # Страница истории запросов
├── settings.html       # Страница настроек
├── about.html          # Страница "О нас"
├── css/
│   ├── style.css       # Основные стили
│   └── animations.css  # Анимации
└── js/
    └── api.js          # API-интерфейс для нейросети
```

## Особенности сайта
- **Адаптивный дизайн**: Полностью оптимизирован для мобильных устройств
- **Нижняя навигация**: Удобное меню для переключения между разделами
- **Интерактивный интерфейс**: С плавными анимациями и переходами
- **API-интерфейс**: Модульная архитектура для интеграции с реальной нейросетью
- **История запросов**: Возможность просмотра и очистки истории
- **Настройки**: Пользовательские настройки для персонализации опыта

## Функциональность
- Отправка запросов к нейросети
- Просмотр результатов обработки
- История взаимодействия с нейросетью
- Настройка параметров работы
- Анимированный интерфейс с визуальной обратной связью

## Технологии
- HTML5
- CSS3 (с использованием CSS-переменных и модерных свойств)
- JavaScript (ES6+)
- Responsive Design
- CSS-анимации

## Использование
Для запуска сайта локально можно использовать простой HTTP-сервер, например:
```
cd /workspace
python3 -m http.server 8000
```

Затем открыть в браузере: `http://localhost:8000`

## Интеграция с реальной нейросетью
Для подключения к реальной нейросети необходимо:
1. Заменить URL в файле `js/api.js`
2. Реализовать аутентификацию (если требуется)
3. Настроить обработку реальных ответов от API
